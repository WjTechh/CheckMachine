# CheckMachine
Sou iniciante, ainda não tenho vivências na área
Aplicativo feito em python com ajuda de IA.
Este aplicativo foi pensado após surgir uma demanda na empresa em que trabalho de suporte de TI, precisavamos fazer um inventário onde teria que coletar informações das máquinas (CPU, RAM, STORAGE, OS, IP e ETC) que se fossem
feitas de forma manual, levaria um bom tempo, entao pensando nisso, desenvolvi o CheckMAchine com auxilio de algumas IA.
O Software coleta as informações da maquina e em tempo real envia para um banco de dados na nuvem, tornando assim possível o acesso a essas informações de qualquer local.
Futuras atualizações - Posteriormente estarei desenvolvendo também uma pagina web, para que possa ser acessado também através do navegador, sem a necessidade de um arquivo .exe
